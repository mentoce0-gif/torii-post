# たまり — Claude Code 初期指示

あなたは iOS アプリ「たまり」を実装する。
このファイルと `SPEC.md` が唯一の正。デザイン議論で増えた詩的説明より、SPEC の禁止事項を優先する。

## 目的
iPhone の生活の端に存在する“場所”。SNS / チャット / メタバース / ゲームにしない。

## 作業順（これを守れ）
1. Xcode プロジェクト骨格（SwiftUI, iOS 17+）
2. 単一画面 `PlaceView`（眺め）
3. 3状態: gaze / seat / waitInput
4. 時間身体の描画（人型禁止の抽象形）
5. 発言の最小入力（送信ボタンなし）
6. 構造物へ時間を焼べる長押し
7. Lock Screen / Live Activity / Dynamic Island（数字禁止）
8. StandBy 用 Widget（静止画系列）

先に Firebase / アカウント / フィード / チャット基盤を作るな。

## 絶対禁止
タブバー、ナビバー、プロフィール、フレンド、一覧、DM、フォロー、いいね、スタンプ、既読、人数表示、残分の常時数字、人型アバター、歩行、エモート、ショップ、クエスト、ログインボーナス、NPC、スクロールログ。

## 実装スタンス
- 画面は原則1枚。窓の向こうに場所がある。
- 何もしない眺めが正常利用。
- 「参加しました」系コピーを出さない。
- 数字で場を説明しない。
- 人が活性化させるUIを足すな。居ることで絵が変わる。

## 成果物
動く iOS アプリ。まずはローカル単機で眺め→在席→減衰→消滅まで。
同期はスタブでよい（`LocalPlaceStore`）。
